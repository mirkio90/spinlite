Installa SpinLite

Dashboard

Serve Chrome o Edge su computer (Web Serial). Collega la ESP32-C3 SuperMini con un cavo USB che trasmette dati.

Versione base

Senza display.

Versione con OLED

Per il display SSD1306 128x32 su GPIO6 (SDA) e GPIO7 (SCL).

Istruzioni

  1. Se la porta seriale non compare nell'elenco, tieni premuto il pulsante BOOT mentre colleghi l'USB, poi rilascialo e riprova.
  2. Scegli la porta e conferma. Con "cancella" attivo la memoria viene azzerata (perdi storico e impostazioni).
  3. A fine installazione scollega e ricollega l'USB.
  4. Per la taratura apri una console seriale a 115200 baud e usa il comando raw mentre giri l'albero a mano; aiuto elenca i comandi.

I file del firmware sono prodotti dalla CI del progetto. Se il pulsante segnala un file mancante, la release non è ancora stata pubblicata.
